# 구슬 미로 v0.1.1

휴대폰 기울기로 구슬을 움직이는 HTML Canvas 게임.

## 실행과 조작
HTTPS에서 index.html 실행. 시작하기를 눌러 기울기 센서를 허용하고 소리를 활성화합니다. 기울기 조작만 지원하며 센서가 없거나 거절하면 안내 화면을 유지합니다. 중심 맞추기로 현재 자세를 보정합니다.

## 화면과 소리
화면 높이에 맞춘 게임 화면과 지원 브라우저의 Fullscreen API를 사용합니다. 전체화면 API 미지원 브라우저는 주소창이 남을 수 있습니다. 홈 화면에 추가하면 지원 환경에서 독립 화면으로 실행할 수 있습니다.
Web Audio로 구르는 소리와 충돌음을 합성하며 속도에 따라 음량이 달라집니다. 백그라운드 이동 시 게임과 소리를 정지하고 이어하기로 재개합니다.

## 검증
JavaScript 문법, 벽 충돌, 전체 경로 통과, 성공과 초기화 시뮬레이션 통과. 실제 iPhone 센서, 화면 및 스피커 청취 검증은 아직 하지 않았습니다.
